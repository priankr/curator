## Andrej Karpathy Skills
url: https://github.com/multica-ai/andrej-karpathy-skills/tree/main
tags: skills, coding

A single CLAUDE.md file that improves how Claude Code writes code, based on Andrej Karpathy's observations about common LLM coding mistakes.

## Microsoft MarkItDown
url: https://github.com/microsoft/markitdown
tags: documents

A Python tool that converts PDFs, Office documents and other files to Markdown, so you can hand them to a model.

## Microsoft Flint
url: https://github.com/microsoft/flint-chart
tags: charts

A chart language built for AI agents. The agent writes a simple chart spec that people can still edit by hand, and Flint turns it into a good-looking chart.

## Diagram Design
url: https://github.com/cathrynlavery/diagram-design
tags: skills, diagrams

A diagram skill for coding agents, with 45 diagram types rendered as self-contained HTML and SVG.

## Reverse Engineer Anything (REA)
url: https://github.com/morluto/rea
tags: skills, security

Reverse engineer anything with an agent, from how an app behaves down to its native binaries.

## Cloudflare Security Audit Skill
url: https://github.com/cloudflare/security-audit-skill
tags: skills, security

A coding agent skill that runs a security audit in phases, checks each finding independently and reports the results in a machine-readable format.

## Cloudflare Computer
url: https://github.com/cloudflare/computer
tags: agents

Gives your agent a computer of its own to work on.

## Google Modern Web Guidance
url: https://github.com/googlechrome/modern-web-guidance
tags: skills, web

Keeps your coding agent up to date with current web best practices.

## Vercel Labs UI
url: https://github.com/vercel-labs/ui
tags: web, design

A library of interface behaviors for agents to build with, with accessibility built in. Works with React, Vue, Svelte, Solid and web components.

## AI Design Skills
url: https://github.com/elayadesign/ai-design-skills
tags: skills, design

Design skills for AI coding tools, including a landing page builder and a Figma designer that sets up tokens, text styles and components.
