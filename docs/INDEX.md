# Curator Docs

The project overview and quickstart are in the root [README.md](../README.md). This page lists every other public doc.

| Doc | Read this when... | Audience |
|-----|-------------------|----------|
| [GETTING-STARTED.md](GETTING-STARTED.md) | You want the user manual: the steps in order from a fresh copy to a live site, including the content format | Site owners and their agents |
| [CONFIG.md](CONFIG.md) | You want to change a setting, a brand colour, a font or a scene colour token. It is generated, so do not edit it by hand | Site owners and developers |
| [DEPLOY.md](DEPLOY.md) | You are putting the site on a static host, attaching a domain, fixing a build error or checking the live site | Site owners |
| [ARCHITECTURE.md](ARCHITECTURE.md) | You are changing how Curator works and need to know how the build, front end and scene are put together | Developers, and agents changing behaviour |
| [examples/sample-brand.json](examples/sample-brand.json) | You want a lean brand config to copy from | Site owners |
