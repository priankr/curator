Poster ink sets

Each poster takes a paper and three inks. The light set uses the light or surface neutral as paper. The inverse set uses the dark neutral or a primary. Inks must reach the minimum contrast against the paper, can never be an avoided pair, and every poster holds at least one primary colour.
